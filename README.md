# 고딸영문법 1단계 · 강의 & 확인 테스트

YouTube 재생목록 [[1단계] 고딸영문법1](https://www.youtube.com/playlist?list=PL_Dpt0EBpdN4e5pPoRnkUXkuvrTqWKJlv)의 62개 강의를 순서대로 듣고, 강의마다 확인 테스트를 푸는 웹 앱입니다.

> 고딸영어 채널의 강의를 공부하기 위해 만든 **비공식 개인 학습 도구**입니다. 영상은 YouTube 임베드로 재생되며, 문제는 강의 내용을 바탕으로 새로 작성했습니다.

## 바로 사용하기 (온라인)

👉 **https://kellyeykim-del.github.io/gottal-grammar/**

설치 없이 브라우저(PC·모바일)에서 바로 쓸 수 있어요. 진도는 사용하는 브라우저에 저장됩니다.

## 내 PC에서 실행

`start.bat`을 더블클릭하면 로컬 서버(http://localhost:5173)가 켜지고 브라우저가 열립니다.
창을 닫거나 Ctrl+C를 누르면 종료됩니다.

> `index.html`을 파일로 직접 열면 YouTube 영상이 재생되지 않을 수 있습니다(YouTube가 `file://` 출처에서의 임베드를 막음). 꼭 `start.bat`으로 실행하세요.
> 포트가 이미 사용 중이면 `start.bat -Port 5174`처럼 다른 포트를 지정하세요.

## 학습 흐름

1. 강의 영상을 앱 안에서 시청 → **85% 이상 시청**하면 테스트가 열립니다.
   (YouTube에서 직접 봤다면 **"YouTube에서 봤어요"** 버튼으로 시청 완료 표시)
2. **확인 테스트**(강의당 5문제, 종합편은 13문제) — 객관식 + 직접 입력
3. **모두 맞혀야(100%) 통과** → 다음 강의가 열립니다.
4. 통과하면 **핵심 정리**가 열리고, 틀린 문제는 **오답노트**에 모입니다.

- 키보드: 숫자키 `1`~`4`로 보기 선택, `Enter`로 확인/다음
- 설정(⚙): 자유 모드(모든 강의 열기), 통과 기준(100/80/60%, 기본 100%), 진도 내보내기/불러오기/초기화
- 진도는 브라우저(localStorage)에 저장됩니다. 다른 PC로 옮길 땐 "진도 내보내기/불러오기"를 사용하세요.

## 구조

```
index.html          앱 화면
css/style.css       스타일 (라이트/다크 모드, 모바일 대응)
js/app.js           플레이어 연동, 시청 추적, 퀴즈, 오답노트
data/lectures-*.js  강의 목록 + 문제 (각 강의 자막 내용을 바탕으로 작성)
serve.ps1           PowerShell 정적 파일 서버
start.bat           실행 스크립트
```

## 문제 추가/수정

`data/lectures-*.js`에서 강의의 `quiz` 배열을 편집하면 됩니다.

```js
{ q: '문제', choices: ['보기1', '보기2', '보기3'], answer: 1, exp: '해설' }        // 객관식 (answer = 정답 index)
{ type: 'input', q: '문제', answer: ['정답', '허용 답안'], exp: '해설' }            // 직접 입력 (대소문자·마침표 무시)
```
