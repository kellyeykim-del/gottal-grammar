# 고딸영문법 1단계 · 강의 & 확인 테스트

YouTube 재생목록 [[1단계] 고딸영문법1](https://www.youtube.com/playlist?list=PL_Dpt0EBpdN4e5pPoRnkUXkuvrTqWKJlv)의 62개 강의를 순서대로 듣고, 강의마다 확인 테스트를 푸는 웹 앱입니다.
선생님이 학생 아이디를 발급하고, 학생별 학습 기록을 확인할 수 있습니다.

> 고딸영어 채널의 강의를 공부하기 위해 만든 **비공식 학습 도구**입니다. 영상은 YouTube 임베드로 재생되며, 문제는 강의 내용을 바탕으로 새로 작성했습니다.

## 접속 주소

👉 **https://kellyeykim-del.github.io/gottal-grammar/**

## 선생님

1. **처음 한 번:** 로그인 화면 아래 **"선생님 계정 만들기"**에서 선생님 계정을 만듭니다. (선생님 계정이 생기면 이 링크는 사라집니다)
2. **학생 관리 → 학생 아이디 발급:** 이름·아이디·비밀번호를 정해 발급하고, 나오는 안내문(주소·아이디·비밀번호)을 복사해 학생에게 전달합니다.
3. **학습 현황:** 학생별 통과한 강의 수, 지금 공부할 강의, 응시 횟수, 남은 오답, 마지막 학습 시각을 봅니다.
   학생을 누르면 **테스트 응시 기록**(일시·점수·틀린 문제와 학생이 쓴 답), **강의별 진도**(시청률·응시·최고 점수), **오답노트**를 볼 수 있습니다.
4. 학생 상세 화면에서 **비밀번호 재설정 / 기록 초기화 / 학생 삭제**가 가능합니다.
5. **강의 보기:** 선생님은 모든 강의와 테스트를 순서 제한 없이 미리 볼 수 있습니다.

## 학생

1. 선생님께 받은 아이디·비밀번호로 로그인합니다.
2. 강의 영상을 앱 안에서 시청 → **85% 이상 시청**하면 테스트가 열립니다.
   (YouTube에서 직접 봤다면 **"YouTube에서 봤어요"** 버튼으로 시청 완료 표시)
3. **확인 테스트**(강의당 5문제, 종합편은 13문제)를 **모두 맞혀야 통과** → 다음 강의가 열립니다.
4. 통과하면 **핵심 정리**가 열리고, 틀린 문제는 **오답노트**에 모입니다.
5. 공부한 기록은 자동 저장되어 다른 기기에서 로그인해도 이어서 공부할 수 있습니다.

- 키보드: 숫자키 `1`~`4`로 보기 선택, `Enter`로 확인/다음

## 구조

```
index.html                     앱 화면 (로그인, 강의, 테스트, 선생님 대시보드)
css/style.css                  스타일 (라이트/다크 모드, 모바일 대응)
js/config.js                   Supabase 주소·공개 키, 통과 기준
js/cloud.js                    로그인, 기록 저장/조회
js/app.js                      플레이어 연동, 시청 추적, 퀴즈, 오답노트
js/teacher.js                  선생님 대시보드
js/main.js                     시작/로그인 흐름
data/lectures-*.js             강의 목록 + 문제 (각 강의 자막 내용을 바탕으로 작성)
supabase/migrations/           DB 스키마와 접근 권한(RLS) 정책
supabase/functions/admin/      계정 발급·비밀번호 재설정·삭제 Edge Function
serve.ps1, start.bat           내 PC에서 실행할 때 쓰는 로컬 서버
```

백엔드는 Supabase(프로젝트 `gottal-grammar`, 서울 리전)를 사용합니다.
학생은 자기 기록만, 선생님은 자기가 발급한 학생의 기록만 볼 수 있도록 DB 정책(RLS)으로 막혀 있습니다.

## 문제 추가/수정

`data/lectures-*.js`에서 강의의 `quiz` 배열을 편집하면 됩니다.

```js
{ q: '문제', choices: ['보기1', '보기2', '보기3'], answer: 1, exp: '해설' }        // 객관식 (answer = 정답 index)
{ type: 'input', q: '문제', answer: ['정답', '허용 답안'], exp: '해설' }            // 직접 입력 (대소문자·마침표 무시)
```
